# HTLS 2026

Static Hindustan Times Leadership Summit 2026 website.

## Upload to GitHub

Extract this ZIP and upload the contents of the `HTLS-2026` folder to your repository root. Keep `index.html` and the `assets` folder together.

## Preview locally

Run `python3 -m http.server 8000` from this folder, then open http://localhost:8000.

## Hosting

For Vercel, import the repository, select **Other** as the framework, leave the build command empty, and use `.` as the output directory.

Fonts load from Google Fonts. News and video links preserve the existing page destinations.
